05 Optimisation

Portefeuille Markowitz

  • Maximisation Sharpe ratio — rendement ajusté au risque
  • Frontière efficiente — trade-off risque/rendement optimal
  • Solution forme fermée — Σ⁻¹ (pas d'optimiseur numérique)
  • Walk-forward backtest — validation out-of-sample
  • Monte Carlo — VaR 95%, CVaR, fan chart
